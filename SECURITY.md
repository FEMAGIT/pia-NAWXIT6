# Security policy

Non aprire issue pubbliche contenenti credenziali, dati personali o dettagli di vulnerabilità sfruttabili. Segnalare privatamente al manutentore del progetto, indicando i passaggi minimi per riprodurre il problema.

Le credenziali devono essere fornite soltanto tramite variabili d'ambiente o un gestore di segreti e non devono essere incluse in commit, allegati o screenshot.
